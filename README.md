## Proyectos destacados

### Mesa de Partes Municipal

Sistema web para centralizar la recepción de documentos y el registro de trámites municipales.

### TypingPro

Plataforma de mecanografía con ejercicios filtrables por idioma y dificultad. Mide velocidad y precisión, guarda el historial de práctica y genera un ranking global con las sesiones registradas.

`Next.js` · `NestJS` · `Prisma` · `TypeScript`  
[Probar la app](https://typing-platform-six.vercel.app/) · [Ver código](https://github.com/DMGB06/typing-platform)

### BusControl QR

App para el transporte escolar municipal. El personal registra la asistencia por QR incluso sin señal y la app sincroniza los registros al recuperar conexión. Las familias pueden seguir el bus en vivo y recibir notificaciones.

`React Native` · `Expo` · `Supabase` · `TypeScript`  
[Ver caso de estudio](https://portafolio-ivory-chi.vercel.app/projects/buscontrol-qr) · [Ver código](https://github.com/DMGB06/bus-attendance-qr)
